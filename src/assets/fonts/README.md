# Bundled web fonts

These production WOFF2 files are bundled locally so the production build has no font-network dependency.

- Inter Variable — Inter Project Authors, SIL Open Font License 1.1
- Outfit Variable — Outfit Project Authors, SIL Open Font License 1.1
- JetBrains Mono Variable — JetBrains Mono Project Authors, SIL Open Font License 1.1

The full license text and copyright notices are preserved in the corresponding `@fontsource-variable/*` packages in `node_modules` and are documented by the package lockfile. Keep this attribution file with the bundled font files when updating them.
